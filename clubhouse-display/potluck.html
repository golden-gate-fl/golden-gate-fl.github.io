Picking potluck tables

Preview. The sign isn't built yet. This shows how it will work.

The sign calls the tables up in a random order, so nobody has to draw numbers from a hat. The host runs it with the button near the microphone.

The button

PressHow
PressPress and let go
Double pressTwo quick presses
HoldHold it down for about 2 seconds

1. Before the potluck: set it up

The host emails the sign the number of tables. The host's email address must be approved to run potlucks. This can be done hours ahead: until the host starts, the sign shows events as usual and the button turns it off and on as usual. The sign replies with a short guide to the button.

2. Start

Hold the button. The sign asks those who need help to go first:

Anyone needing help
please go first

3. Call the tables

Press once each time the next table should go up. The sign picks a table that hasn't been called yet and adds it to the list:

Food: 12, 7, 3
 

The newest numbers are on the right; when the line is full, the oldest drop off. The last table is marked:

Food: … 9, 14, 1, 20 (last)
 
  • A second press within 5 seconds is ignored, so a shaky press doesn't skip a table.
  • Once called, a table stays called: there's no undo.
  • Pressing after the last table does nothing.

4. Seconds

After the last table, double press:

Food: seconds, anyone!
 

5. Dessert

Hold the button. Then press once for each table, as for the food. Dessert goes in the reverse order of the food, so the tables that ate last get dessert first. Dessert can start at any time, even if not every table has been called for food.

Food: … 9, 14, 1, 20 (last)
Dessert: 20, 1, 14

6. Finish

Hold the button, and the sign goes back to showing events. If nobody presses the button for 3 hours, the sign finishes the potluck by itself.

If the sign restarts during the potluck, it carries on where it left off. If the potluck is set up but never started, the setup ends at midnight.
