Doing a 50/50 draw

Preview. The sign isn't built yet. This shows how it will work.

The sign draws the winning ticket at random from all the tickets handed out. The host runs it with the button near the microphone.

1. Set it up

After the tickets are sold, the host emails the sign the first and last number of each roll of tickets handed out, and the winner's prize. The host's email address must be approved to run 50/50 draws. As soon as the email arrives, the sign shows the prize (and turns itself on if it was off):

50/50: $54 for winner
 

The sign replies with how many tickets there are. If two rolls have tickets ending in the same 4 digits, the reply warns you to call out the whole number.

2. Draw

Press the button. The sign shows the winning ticket, with the last 4 digits set apart so they're easy to read out:

50/50: $54 for winner
Ticket 12 3456

3. Winner not here?

Press again to draw another ticket. The sign never draws the same ticket twice.

4. Finish

Hold the button for about 2 seconds, and the sign goes back to showing events. If nobody does, it goes back by itself after 3 hours.
